## 3步开玩
### 1. 搜游戏
打开 TC，输入 APPID 或游戏全名，一键精准定位。搜不到？V1.9 已支持自动缺失记录，无需手动提交。

### 2. 点入库
选中后点击"入库"，TC 自动处理一切授权。网络波动时追加 `-2` 后缀走备用线路。

### 3. 重启 Steam
重启 Steam 客户端，游戏立即出现在你的库中。不用了？设置中心一键还原，无痕恢复。
