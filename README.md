## 📖 三分钟快速上手教程
1. **检索目标游戏**：启动工具箱输入游戏名字或者App‑ID；碰到缺失资源程序会自动后台提交补录申请
2. **执行一键入库**：点击入库按钮等待程序自动处理；网络不稳定时末尾添加 `-2` 使用备用线路
3. **重启Steam客户端**：游戏成功加载至你的库内；不需要时一键清理改动、恢复原生Steam环境


## ✨ 为什么选择 Titan Core
1. **7万+云端游戏资源库**
搭载全天候自动维护云端数据库，收录海量Steam商店游戏；百分之九十九的游戏均可一键入库，无需手动导入、更新本地清单文件。

2. **批量入库 + 复合式游戏检索**
支持一次性批量添加多款游戏；支持游戏全称、AppID两种搜索方式；网络环境较差的时候，在检索内容末尾添加 `-2` 即可启用备用线路执行入库。

3. **程序、游戏清单增量自动更新**
内置热更新引擎，软件升级不需要重新安装；后台自动同步云端游戏清单，保证本地游戏数据库时刻为最新版本。

4. **双兼容内核自由切换**
内置 SteamTools、OSTools 两套运行内核，可以一键切换，解决DLL缺失、系统环境冲突、入库失败等常见故障。

5. **三节点智能轮询网络优化**
3条独立服务器节点自动测速择优接入，实时检测链路延迟；遭遇网络抖动、连接超时自动更换通道，无需人工手动切换节点。

6. **Steam运行环境全自动修复**
自动校验本地Steam客户端文件完整性；入库流程开始前自动关闭Steam进程；任务结束弹窗提示重启客户端；支持一键无痕复原全部环境改动。

7. **云端储存入库记录**
所有已入库游戏记录同步至云端；更换电脑、重装操作系统之后能够一键恢复你的游戏列表。

8. **Denuvo加密游戏识别预警**
加密游戏侦测模块，识别搭载Denuvo以及各类强制加密防护的游戏，提前拦截无效入库请求，节约你的等待时间。

9. **零残留安全运行机制**
主流杀毒软件无告警；程序不会索取系统最高权限、不写入敏感注册表项、不存在后台常驻进程；随时一键还原Steam原生环境，不留任何修改痕迹。

10. **MOD资源与创意工坊辅助工具**
支持Wallpaper Engine创意工坊项目订阅加速、N网MOD高速下载；工具箱附带多款休闲内置小游戏，后续持续新增内容。

## ⚙️ 新版特点
- **程序自愈机制**：软件意外崩溃之后自动重启并且排查故障，生成完整错误日志方便排查问题
- **全新重构搜索引擎**：游戏检索响应速度大幅度提升，音频律动功能正式回归
- **自动补库系统**：遇到云端暂未收录的游戏，程序自动提交记录，后台工作人员后续增补入库清单
- **备用线路快捷指令**：游戏名称或是AppID尾部追加 `-2`，强制调用备用网络通道

## 🧩 扩展能力
1. **TC‑D‑TOOL**：锁定当前游戏版本，阻止Steam自动更新，用来保护MOD配置、本地存档文件
2. **Denuvo授权辅助工具**：配合加密游戏侦测雷达，处理受防护游戏相关操作
3. **480联机测试通道**：适配部分游戏的本地联机测试通道，联机功能长期迭代优化
